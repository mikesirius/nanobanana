# 开发日志（Nano Banana）

本文记录本次核心功能实现与服务器端 GitHub 登录的完整过程与要点，并结合《AI 编程加强营学习手册1》中的方法论进行复盘。

## 今日目标
- 打通“图片上传 → 模型生成 → 前端展示”的最小可用闭环。
- 接入 Supabase（服务器端）GitHub 登录，安全管理用户会话。

## 实施步骤
1) 图片生成闭环
- 后端路由：`app/api/generate/route.ts:1`
  - 接收 multipart 表单，字段：`image`、`prompt`。
  - 将 `File` 转 `data:` URL（base64）：`fileToDataUrl()`。
  - 调用 OpenRouter Chat Completions：`google/gemini-2.5-flash-image-preview`，构造 `messages[0].content = [text, image_url]`。
  - 解析返回的图片 URL 列表并输出 `{ images }`。
- 环境变量：`.env.local:1`
  - `OPENROUTER_API_KEY`（可选：`OPENROUTER_SITE_URL`、`OPENROUTER_SITE_NAME`）。

2) 服务器端 GitHub 登录
- Supabase 客户端（服务端）：`lib/supabase/server.ts:1`
  - 基于 `@supabase/ssr` 与 Next.js `cookies()`，实现 `createClient()`（注意 Next 16 的异步 `cookies()`）。
- 发起 OAuth：`app/auth/github/route.ts:1`
  - `supabase.auth.signInWithOAuth({ provider: "github", options: { redirectTo: <origin>/auth/callback } })`。
- 回调换取会话：`app/auth/callback/route.ts:1`
  - 读取 `code`，`supabase.auth.exchangeCodeForSession(code)`，成功后重定向首页。
- 错误页：`app/auth/error/page.tsx:1`
- 登出路由：`app/auth/signout/route.ts:1`（POST）
- UI 展示登录态
  - 服务端获取用户并透传：`app/page.tsx:1`
  - 头部组件根据登录态展示头像/昵称与登出按钮：`components/header.tsx:1`
- 依赖：`package.json:1`
  - 新增 `@supabase/supabase-js`、`@supabase/ssr`
- 环境变量：`.env.local:1`
  - `NEXT_PUBLIC_SUPABASE_URL`、`NEXT_PUBLIC_SUPABASE_ANON_KEY`

## 关键实现与细节
- OpenRouter 请求体
  - `model: "google/gemini-2.5-flash-image-preview"`
  - `messages: [{ role: "user", content: [{ type: "text", text: <prompt> }, { type: "image_url", image_url: { url: <dataURL> } }] }]`
- 错误兜底
  - 后端严格校验空 `prompt`/缺图、API 错误时返回明确 message。
- 安全
  - API Key 仅存放在服务端环境变量，调用经由服务端路由代理完成。
  - Supabase 会话通过 `@supabase/ssr` 与 Next `cookies()` 管理，不在客户端暴露机密。

## 遇到的问题与修复
- 问题：Next.js 16 中 `cookies()` 为异步，原同步调用触发错误。
  - 现状：`lib/supabase/server.ts:1` 将 `createClient()` 改为异步，并在页面/路由中以 `await createClient()` 使用。
- 兼容性：在 Server Component 环境仅读取 Cookie，写入 Cookie 操作仅在 Route Handler/Server Action 中进行。

## 运行与验证
- 本地运行：`pnpm dev`（.env.local 已读取）
- 生成流程：
  1. UI 选择图片并输入 Prompt。
  2. 点击 Generate，后端经 OpenRouter 请求模型生成图片。
  3. Output Gallery 展示返回图片。
- 登录流程：
  1. Header 点击 Sign In → 跳转 GitHub 授权。
  2. 回到 `/auth/callback`，交换会话并重定向首页。
  3. Header 显示头像/昵称与 Sign Out。

## 控制台设置（Supabase/GitHub）
- Supabase 启用 GitHub Provider。
- Supabase Auth → URL Configuration：
  - Site URL：`http://localhost:3000`
  - Additional Redirect URLs：`http://localhost:3000/auth/callback`
- GitHub OAuth App：Authorization callback URL 按 Supabase 文档配置。
